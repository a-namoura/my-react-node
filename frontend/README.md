# React Frontend

This is the React frontend for the [React + Express Starter](../). It currently displays a Hello World page and a button. The frontend and backend are separate; the UI is not connected to the API yet.

## Run

```bash
npm install
npm start
```

Open http://localhost:3000.

## Scripts

- `npm start` — development server
- `npm test` — test runner
- `npm run build` — production build

See the [repository README](../README.md) for backend and Docker setup.
